### The Problem

Building on Mezo today means juggling multiple tools:

- Setting up a local Solidity environment
- Configuring RPC endpoints and wallet connections
- Manual contract deployments with constructor args
- Separate verification steps on the explorer
- No easy way to discover and integrate existing Mezo protocols

This friction slows builders down and raises the barrier to entry — especially for developers new to the ecosystem.

---

### The Solution

**Mezo IDE** — a browser-native development environment purpose-built for Mezo builders.

| Step | What You Get |
|------|--------------|
| **Write** | Full Solidity editor with OpenZeppelin support, syntax highlighting, auto-completion, and real-time error detection. Zero setup. |
| **Deploy** | One-click deployment to Mezo Mainnet or Testnet. Constructor arguments parsed and handled automatically. |
| **Verify** | Contracts auto-verified on Mezo Explorer immediately after deployment. No manual steps. |
| **Interact** | Built-in transaction simulator, contract interaction panel, and protocol registry to explore live Mezo protocols. |
| **Ship** | Export a complete Next.js + wagmi dApp starter from any deployed contract. Go from contract to frontend in seconds. |

---

### For Developers

**What you can do today:**

```
1. Open the IDE in your browser
2. Connect your wallet (MetaMask, etc.)
3. Write or paste your Solidity contract
4. Click "Compile" — instant feedback with OpenZeppelin imports resolved
5. Click "Deploy" — live on Mezo Mainnet in one transaction
6. Contract auto-verified on Explorer — share the link immediately
7. Use the Interact panel to call functions, or export a full dApp starter
```

**Features that matter:**

- **Smart Templates** — ERC-20, NFTs, Staking, DEX, Governance — start with production-ready code
- **Protocol Registry** — Browse deployed Mezo protocols, view ABIs, generate TypeScript interfaces
- **Shareable Links** — Share your contract code via URL for collaboration and code reviews
- **Transaction Simulator** — Preview transaction outcomes before spending gas
- **dApp Generator** — Export Next.js + wagmi + viem project with your contract pre-configured
